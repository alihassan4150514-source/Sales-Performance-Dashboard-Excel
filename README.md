# Sales Performance Dashboard — Excel

An Excel-based sales performance dashboard built with the Sample Superstore dataset as part of the Elevvo Data Analytics Internship.

## Project Overview

This project analyzes sales and profitability across time, regions, product categories, customer segments, products, and customers. The workbook contains cleaned source data, PivotTable summaries, charts, KPI cards, and slicers for interactive filtering.

## Tools Used

- Microsoft Excel
- PivotTables
- Excel charts
- Slicers

## Dashboard Features

- KPI cards: Total Sales, Total Units Sold, Total Profit, and Average Discount
- Monthly sales analysis by year and month
- Sales by region, category, and customer segment
- Top 10 products by sales
- Top 10 customers by sales
- Profit by category and region
- Slicers for Month, Year, Category, Segment, and Region

## Analysis Sheets

The workbook includes these analysis sheets:

1. Monthly Sales
2. Region Sales
3. Category Sales
4. Segment Sales
5. Top 10 Products
6. Top 10 Customers
7. Profit by Category
8. Profit by Region

It also includes the **Sample - Superstore** source-data sheet and the **Dashboard** sheet.

## Key Findings

- Total sales: **$2,297,200.86**
- Total profit: **$286,397.02**
- West recorded the highest regional sales (**$725,457.82**) and profit (**$108,418.45**).
- Technology generated the highest profit by category (**$145,454.95**).
- Consumer was the largest customer segment by sales (**$1,161,401.35**).

## How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Select the **Dashboard** sheet.
4. Use the Month, Year, Category, Segment, and Region slicers to filter the available summaries and charts.
5. Review the analysis sheets for the underlying PivotTable summaries.

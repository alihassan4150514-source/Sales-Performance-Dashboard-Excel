# Sales Performance Dashboard — Excel

An interactive sales performance dashboard created in Microsoft Excel using the Sample Superstore dataset as part of the Elevvo Data Analytics Internship.

## Project Overview

This project transforms raw retail sales data into a set of PivotTable summaries and visual charts to explore sales and profitability across time, regions, product categories, customer segments, products, and customers.

## Work Completed

- Cleaned and standardized the Order Date and Ship Date fields.
- Organized the dataset for analysis.
- Created PivotTables for:
  - Monthly sales by year
  - Sales by region
  - Sales by category
  - Sales by customer segment
  - Top 10 products by sales
  - Top 10 customers by sales
  - Profit by category
  - Profit by region
- Built eight charts and arranged them on a dashboard.
- Added KPI summaries for key business metrics.

## Key Findings

- Total sales: **$2,297,200.86**
- Total profit: **$286,397.02**
- West region recorded the highest regional sales (**$725,457.82**) and profit (**$108,418.45**).
- Technology generated the highest profit by category (**$145,454.95**).
- Furniture generated comparatively low profit (**$18,451.27**) despite substantial sales.
- Consumer was the largest customer segment by sales (**$1,161,401.35**).

## Tools Used

- Microsoft Excel
- PivotTables and PivotCharts

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Open the **Dashboard** sheet to view the KPI summaries and charts.
4. Use the PivotTable sheets to inspect the underlying summaries.
